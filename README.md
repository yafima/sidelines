
1.command to run "npx playwright test performance-testing.spec.js"
The script automates a Lighthouse audit on a specified list of URLs.
It evaluates website performance, accessibility, best practices, and SEO.
Creating json and csv file to the lighthouse directory.
The purpose of the script is to verify SEO metrics indicators on a webpage.

2.command to run "npx playwright test resource-validation.spec.js"
The purpose of the script is to catch broken resources (scripts, stylesheets, and images) on a webpage by monitoring network requests and verifying that all critical assets load successfully without errors.

3.command to run "npx playwright test api-data-retrieval.spec.js"
The purpose of the script is to verify that the API responses are valid by checking that each post has a non-empty title, a non-empty body, and a numeric userId.
